# Prompt para IA

Crea una página web educativa e interactiva de cuentos infantiles llamada “Había una vez…” con estilo moderno, cálido, amigable y didáctico, inspirada en una biblioteca mágica. La interfaz debe verse elegante, limpia y acogedora, con colores suaves, tonos pastel y un diseño intuitivo para niños y familias.

## Requisitos generales
- La web debe tener diseño responsive para móvil, tablet y escritorio.
- Debe verse como una biblioteca de cuentos con un ambiente mágico y divertido.
- Debe incluir secciones de cuentos, audiocuentos, videos, actividades, personajes y retos.
- La navegación debe ser clara, accesible y visualmente atractiva.
- Debe incluir una barra superior con logo, menú principal y buscador.
- Debe tener un estilo didáctico, visualmente atractivo y fácil de usar para niños.

## Secciones sugeridas
1. Hero principal con texto promocional y botón de explorar.
2. Biblioteca de cuentos con cards por categoría.
3. Sección de audiocuentos.
4. Sección de videos educativos.
5. Actividades y juegos interactivos.
6. Personajes y cuentos favoritos.
7. Sección de logros o progreso del lector.
8. Footer con información general.

## Estilo visual
- Colores: suaves pastel, violetas, rosas, amarillos, verdes y azules.
- Tipografía amigable y clara.
- Bordes redondeados, sombras suaves y fondos con degradados.
- Elementos como estrellas, nubes, luna, árboles y formas mágicas para reforzar la temática.
- Usar un aspecto visual luminoso y cálido.

## Interactividad
- Botón para abrir cada cuento en un modal o lector.
- Filtros por categoría: aventura, princesas, animales, fantasía, moral, etc.
- Favoritos y guardado en localStorage.
- Búsqueda por nombre del cuento.
- Botones para escuchar narración, ver video o abrir actividad.
- Animaciones ligeras, hover y microinteracciones.

## Contenido sugerido
- Cuentos con títulos como: “La liebre y la tortuga”, “Caperucita Roja”, “Hansel y Gretel”, “Los tres cerditos”, “El patito feo”, “La cenicienta”, “Ricitos de oro”, “La bella y la bestia”, “Pulgarcito”, “El delantal de la abuela”, etc.
- Cada cuento debe tener: título, mini descripción, categoría, edad, duración, icono, botón de lectura, audio y video.

## Tecnología
- HTML5 semántico.
- CSS3 con diseño creativo y responsivo.
- JavaScript para interactividad, filtros y almacenamiento local.
- Puede incluir manifest PWA con soporte offline.

## Objetivo final
Crear una web completa, moderna y educativa que invite a leer, escuchar, aprender y jugar, con una interfaz encantadora de “biblioteca mágica” para niños.

## Ajustes visuales específicos
- Usa la imagen del logo desde assets/logo.jpeg.
- La barra superior debe quedar centrada, elegante y bien equilibrada.
- El logo debe verse visible, no recortado ni perdido en el fondo.
- La interfaz debe sentirse didáctica, amigable y ordenada.
- Mantén el estilo infantil, claro y visualmente atractivo.
